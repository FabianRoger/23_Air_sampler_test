# Air eDNA Sampler Comparison

Analysis repository for a study comparing eight air sampling devices for environmental DNA (eDNA) metabarcoding across multiple taxonomic groups.

## Study overview

We deployed eight air samplers (six active, two passive) at eight sites in Switzerland to evaluate their performance for airborne eDNA-based biodiversity monitoring. Each sampler was operated for 30 minutes and 5 hours (active) or 2 weeks (passive). We performed eDNA metabarcoding for five organism groups (bacteria, fungi, plants, insects, vertebrates) using group-specific primers and assessed species richness, community composition, and concordance among samplers.

### Samplers

- **Active (with air pump):** Kärcher, Coriolis, Sass, Hepa, Burkhart, Electrostatic
- **Passive (no air pump):** MWAC, WSL_Filter
- **Aerial (drone-mounted):** Drone (Coriolis, at one site only)

### Sites

Eight sites in the greater Bern and Zürich region, Switzerland: Dübendorf, Talent, Coruz, Haslibach, Leugene, Gäbelbach, Weierbach, Riedgraben.

### Taxonomic groups and primers

| Group | Marker | Primer pair | Reference database |
|-------|--------|-------------|-------------------|
| Bacteria | 16S rRNA | 515F / 806R | RDP trainset 19 |
| Fungi | ITS2 | fITS7 / ITS4 | UNITE + GBIF backbone |
| Plants | ITS2 | ITS-S2F / ITS4 | PLANiTS + GBIF backbone |
| Insects | COI | mlCOIintF / jgHCO2198 | BOLD + MIDORI + GBIF |
| Vertebrates | 16S rRNA (large ribosomal) | 16Smam1 / 16Smam2 | MIDORI + GBIF |

Plants were also detected via the fungi ITS2 primer (cross-amplification) and results from both primers are compared.

## Analysis workflow

The analysis proceeds in four stages:

1. **Reference database preparation** (`Prepare_RefDB.Rmd`): Downloads and formats taxonomic reference databases, matches taxonomy to the GBIF backbone for standardized nomenclature.

2. **Demultiplexing** (`Demultiplexing_by_Primer.Rmd`): Separates pooled sequencing reads by primer pair.

3. **Sequencing analysis** (`Seq_Analysis_*.Rmd`): Per-group bioinformatics pipeline using DADA2 for denoising, SWARM/LULU for OTU clustering, and SINTAX/BLAST for taxonomic assignment. Outputs are ASV count tables and taxonomy in `Data/{Group}/out_final/`.

4. **Data analysis** (`Data_Analysis_*.Rmd`): Per-group statistical analysis including contamination assessment, species richness estimation, community composition (NMDS, PERMANOVA), sampler concordance, and group-specific analyses. These scripts produce the manuscript figures and statistics.

## Contamination assessment

Each analysis script includes a standardized contamination assessment:

- **Lab controls**: Extraction blanks (n=9) and PCR negative controls (n=3) identify laboratory contamination. For each OTU found in lab controls, twice the maximum read count across all controls is subtracted from all samples.
- **Field controls**: Sampler-specific field blanks (2 per sampler type) represent handling/transport contamination. OTUs with mean abundance higher in field controls than in samples (ratio > 1) are flagged, and twice the maximum field control reads are subtracted from all samples.
- **Decontam**: The `decontam` R package is applied using a prevalence-based method to identify contaminants statistically.

## Requirements

Analysis was performed in R (≥ 4.3). Key packages:

- `dada2`, `Biostrings`, `ShortRead` — sequencing analysis
- `vegan` — community ecology (diversity, ordination, PERMANOVA)
- `dplyr`, `tidyr`, `readr`, `readxl` — data manipulation
- `ggplot2`, `ggh4x`, `corrplot` — visualization
- `decontam` — contamination identification
- `eulerr` — Euler/Venn diagrams
- `here` — project-relative paths
- `data.table` — fast data operations (LULU)
